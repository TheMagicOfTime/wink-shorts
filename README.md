# Wink Shorts · Фишер

Демонстрационная лента из 20 вертикальных роликов по первым трём сериям «Фишера».

## Как смотреть

Распакуйте архив и откройте [index.html](index.html) в браузере. Листайте ролики колесом мыши, стрелками ↑ и ↓ или свайпом по видео. Если открыть комментарии, обсуждение будет меняться вместе с роликом. Лайки и новые комментарии сохраняются в браузере зрителя.
